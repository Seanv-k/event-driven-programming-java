# Week 2: Observer Pattern Reflection

The Observer Pattern is a behavioural design pattern that allows one object to notify other objects when its state changes. I learned that it is useful in event-driven programming because it allows different parts of an application to communicate without depending directly on each other.

I also learned how to create a custom Observer Pattern using Java interfaces, ArrayLists and methods such as addObserver(), removeObserver() and notifyObservers().

The practical activities helped me understand the difference between tightly coupled systems and loosely coupled systems.

I would choose the custom Observer Pattern for a plain Java application because it provides flexibility and control. For a JavaFX application, I would choose JavaFX Bindings.
